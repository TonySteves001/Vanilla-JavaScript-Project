
# JavaScript Projects

> Using JavaScript to solve problems, power projects, and occasionally test my patience.

Welcome to my JavaScript workspace. This repository contains projects built using **Vanilla JavaScript and Node.js**, exploring the language's core features, runtime capabilities, and practical applications.

The focus is on understanding JavaScript deeply, strengthening problem-solving skills, and applying the language to build practical solutions without relying on frameworks.
